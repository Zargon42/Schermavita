# Screenshot provenance

Captured on 25 October 2026 from the validated SchermaVita 0.6.2 debug APK on a disposable Android 16 emulator at 480 × 1000 pixels. These are direct PNG screenshots of the actual app, not mockups or generated UI. No image edits, compositing or overlays were applied.

The app was cleared before seeding. No private history package or personal database was loaded. All displayed people, clubs, equipment, lessons, bout scores, step/sleep totals and ratings were invented for this demonstration. Integrations were not granted live access. The on-screen permission status is retained honestly.

- `today.png`: daily totals, quick entry and configurable trackers.
- `fencing.png`: a fictional active practice session, lesson and recorded results.
- `insights.png`: a chart calculated by the app from invented bout results.

The exact invented payloads are in [synthetic-records.json](../demo/synthetic-records.json). This is a documented set of SQLite record payload examples for developer inspection, not an end-user import package. `Demo`, `Example` and `Synthetic demo` labels make their origin explicit. The fixture contains no source attachments, private records or credentials.

The screenshot session changes emulator data only; application code and the required regression-test inventory are unchanged.
